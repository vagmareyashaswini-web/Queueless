# QueueLess

QueueLess is a Smart Virtual Queue Management System designed to reduce waiting time in hospitals, banks, colleges, and service centers.

## Features
- Virtual Token Generation
- Queue Tracking
- Digital Queue Management
- Reduced Waiting Time

## Technologies Used
- Python
- Django
- MySQL
- HTML
- CSS

## Objective
To improve customer experience by replacing physical queues with a digital queue management system.
